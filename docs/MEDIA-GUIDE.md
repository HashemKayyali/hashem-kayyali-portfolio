# Media Replacement Guide

Keep the existing filenames and use WebP images.

## Profile photo

```text
public/images/hashem-profile.webp
```

Recommended ratio: `4:5`.

## Project folders

```text
public/projects/
├── basket-beats/
├── bike-tower/
├── eventies/
├── glitzz-lab/
├── the-terminal-nfc/
├── outreach-automation-platform/
├── vr-cycling/
├── bike-land-smart-cycling-trainer/
└── traffic-flow-analytics-studio/
```

Each project can include:

```text
cover.webp
screenshot-01.webp
...
screenshot-10.webp
```

The cover appears first in the project gallery. Missing screenshot numbers are ignored automatically.

Recommended cover size: `1600 × 1000 px` with a `16:10` ratio.

Avoid exposing customer names, phone numbers, emails, credentials, payment details, or private administrative data.
