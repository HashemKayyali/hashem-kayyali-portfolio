# Portfolio V2 typography

Instrument Sans and Geist Sans: genuine upright variable sources from the Google Fonts upstream repository. SIL Open Font License 1.1 copies are beside the fonts. Self-hosted; no runtime Google/Vercel requests.

Instrument: https://github.com/google/fonts/tree/main/ofl/instrumentsans
Geist: https://github.com/google/fonts/tree/main/ofl/geist (https://vercel.com/font)

Weight axes restricted to Instrument 500–700, Geist 400–600; Instrument width fixed at 100. Glyph subset includes Latin/Latin Extended for English, German, French and Spanish, punctuation and every Latin glyph in the approved dictionaries. FontTools WOFF2/Brotli; no application dependency added. Arial fallback width and vertical metrics adjusted from the font tables. Original Arabic typography and font faces unchanged.
