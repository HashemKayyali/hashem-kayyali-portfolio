# Portfolio font sources

Downloaded 2026-10-11 from the official Google Fonts CSS API. Families and
normal style match the existing portfolio: Inter 300–800 and Roboto Slab
400–800. These are variable WOFF2 files, with Latin and Latin Extended
subsets. `fonts.css` retains Google's unicode ranges and `font-display: swap`.
Arabic continues to use the site's existing system fallback.

CSS request:
https://fonts.googleapis.com/css2?family=Inter:wght@300..800&family=Roboto+Slab:wght@400..800&display=swap
